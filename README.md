# sql-plsql-reporting-system
Enterprise-style SQL and PL/SQL reporting system

## Problem Statement
The goal of this project is to design and implement an enterprise-style
reporting system using SQL and PL/SQL. The system stores structured data
and generates meaningful business reports through complex SQL queries
and automated PL/SQL procedures.

## Features
- Relational database schema with primary and foreign key constraints
- SQL-based reports using joins, aggregations, and filtering
- PL/SQL stored procedure for monthly report generation
- Debugging and root cause analysis of SQL and PL/SQL issues
- Data validation and testing for report accuracy

## Database Design
The system includes the following tables:
- Departments
- Employees
- Projects
- Employee_Projects
- Monthly_Reports

## Sample Reports
- Department-wise salary report
- Project-wise cost report
- High-utilization employee report
- Monthly salary summary using PL/SQL

## Technologies Used
- Oracle SQL
- PL/SQL

## Key Learnings
- Writing optimized SQL queries for reporting
- Using PL/SQL to automate data processing tasks
- Debugging SQL errors and performing root cause analysis
- Understanding enterprise-style data workflows

## Future Enhancements
- Add exception handling in PL/SQL
- Implement triggers for automated validations
- Extend reports with date-based filtering
